## 朋友如何协作 / 反馈

仓库是公开的。朋友**不需要**改代码，用 GitHub Issue 提交信息即可：

1. 打开仓库：https://github.com/yunfei-xu/italy
2. 点 **Issues** → **New issue** → 选「行程反馈」
3. 或直接打开：https://github.com/yunfei-xu/italy/issues/new?template=feedback.yml
4. 写上订票、酒店、时间等，提交

Miles 收到 Issue 后，可以让 Agent 更新 `index.html`，大家刷新行程链接就能看到最新内容。

> 注意：不要在 Issue 里发护照、付款码、完整证件号等隐私信息。
