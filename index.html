威尼斯

3 晚 · 9/27–9/30 · 双年展 + 本岛 · 7 人同行

住宿

  • 需求：7 人住一起 · 至少 4 间房 · 3 张双人床 + 1 张单人床
  • 推荐优先：Mestre 大公寓（如 Natalia’s big flat）——床位够、评分高、拖行李轻松，去火车站租车也方便；进本岛火车/公交约 10–15 分钟
  • 想住本岛：选 Cannaregio / 火车站附近，或 San Polo（注意陡楼梯）
  • 现状：Claire/阿文原订「Acquadiluna Yellow」；若改 7 人同住或改成 3 晚（9/27–9/30），需取消/改期后重订
  • 入住提醒：威尼斯住宿税现金支付常见；晚到可能有加价，Miles/Claire/阿文约 19:15 落地，提前告诉房东

交通

  • 机场 → 住宿：马可波罗机场 → 本岛可坐 Alilaguna 快船或巴士到 Piazzale Roma / 火车站；若住 Mestre，机场大巴/打车更直接
  • 本岛出行：走路为主 + vaporetto（水上巴士）。建议买 48h/72h 交通卡（含 vaporetto，不含机场线时要看清票种）
  • 双年展：主场馆 Arsenale / Giardini，坐 vaporetto 更省脚力
  • 9/30 离开：威尼斯火车站（Santa Lucia）或 Mestre 附近取租车；优先 7 座或行李空间够的车，并确认可上高速公路
  • 注意：本岛几乎不能开车；取还车在火车站 / Mestre / Piazzale Roma 一侧

  • 午餐：双年展日吃馆内简餐，或 bacaro 点 cicchetti（威尼斯小食）+ 一杯酒
  • 晚餐方向：Cannaregio、犹太区、Dorsoduro 比圣马可广场周边更划算；7 人尽量提前订位
  • 必尝：cicchetti、鲜鱿鱼/墨鱼汁意面、提拉米苏；开胃酒 Spritz
  • 避坑：圣马可广场桌位贵；留意菜单 coperto（座位费）
  • 9/27 晚：落地已晚，住处步行 5–10 分钟内解决，或超市简餐

多洛米蒂

驻 Brixen（布里克森）· 4 晚 · 9/30–10/4 · 自驾

住宿

  • 基地：Brixen / Bressanone（或邻近 Chiusa / Klausen）——去 Seceda、Braies、Funes 都合适
  • 房型：优先能住 7 人的公寓/酒店连房；必须确认有停车位
  • 加分项：含早餐、有洗衣机、距高速口近；问是否提供 Brixen Card / 游客卡（或含公交缆车优惠）
  • 入住：9/30 下午到；10/4 早晨退房后南下还车

交通

  • 租车：9/30 威尼斯火车站取车 → 10/4 同一带还车；自动挡、行李空间要够（7 人优先大型旅行车/7 座）
  • 路书：威尼斯北上经 A27/A22 → Brixen；单程约 2.5–3.5h，留意过路费
  • 山里开车：弯多、雨雾减速；Braies 与热门停车场尽量早到
  • 缆车：Ortisei 上 Seceda / Alpe di Siusi；日票价格以当年官网为准（此前约 €65/人量级）
  • 10/4：预留还车 + 赶火车缓冲，建议中午前到威尼斯火车站
